# TechLab

TechLab 用于探索技术方向、比较候选方案、开发可运行的 Demo，并依据实验判断方案的可行性、性能和适用条件。

| 入口 | 内容 |
| --- | --- |
| [研究专题](research/README.md) | 按问题组织候选方案、验证标准和评估结论 |
| [Demo 工程](demos/README.md) | 按可运行工程组织代码、样例、实验入口和复跑说明 |
| [专题模板](templates/research.md) | 新建专题时使用 |
| [Demo 工程模板](templates/demo-project.md) | 新建可运行工程时使用 |

## 组织方式

专题放在 `research/<topic>/`。一个专题可以比较多个 Demo，也可以基于已有资料得出结论。专题 README 记录研究问题、候选方案、验证标准和相关入口，有实测结果时可另写 `evaluation.md`。

工程放在 `demos/<project>/`。一个工程可以包含多个实验，由它自己的构建工具管理依赖和运行方式。能共用环境和依赖的实验可以放进同一工程。有独立构建或运行环境需求时，再新增工程。

专题和工程通过相对链接关联。工程 README 负责说明怎么运行，专题文档负责说明实验结果能支持什么结论。新增专题或工程后，在对应索引中补上入口。

## 评估与孵化

开始验证前，先写清要回答的问题、通过条件和必要的对照基线。做性能比较时，记录被测版本、环境、输入和复跑命令，并链接原始数据。结论写明适用条件、失败场景和仍待验证的边界。

如果成果有明确的独立使用和维护需求，可以把实现、构建配置、样例与验证方法迁到单独的仓库。TechLab 保留评估结论、原型版本和新仓链接。
