# 题目排版 DSL 草案 v0.1

这版草案面向空白题面。同一道题可以排成屏幕上的一张题卡，也可以排进纸质试卷。作者先写题干、选项、材料、小题和作答区，再指定哪些字要加点、哪些选项要分列、哪些地方要留出书写空间。点击、输入、笔迹和答案提交属于使用题面的应用。

两层的关键字、属性名和枚举值统一使用小写英文。题干、选项、材料和图片说明按原语言书写，同一道题可以混排中英文。下表中的 `<kind>`、`<text>` 等表示作者要填的内容，尖括号省略。

## 题型层怎样描述题面

一份源文写一道顶层题。`@question` 开始题目，`@` 开头的结构指令独占一行，每两格空格缩进一级，同级按书写顺序展示，退回上一级缩进就结束当前块。形如 `#price` 的名称是标识，首字符为小写英文字母，后续可用小写字母、数字、连字符，在一份源文内唯一。显示的题号与选项序号由排版生成。

| 写法 | 用途和约束 |
| --- | --- |
| `@question <kind> #id` | 类型取 `choice`（选择）、`fill-in`（填空）、`reading`（阅读）或 `short-answer`（简答）。 |
| `@stem` | 每道题或小题恰好一个。下一级写正文。 |
| `@options #id` | 选择题恰好一组，至少两个选项。每项占一行，写成 `- #id <text>`。选项可含文字、公式或图片。 |
| `{{blank #id}}` | 嵌在正文里的作答区，位置由前后文确定。选择题题干末尾的括号和填空题句中的横线都能这样定位。普通文字中的括号、下划线照原文显示。 |
| `@answer-area #id` | 独占一块的作答区，与题干或选项组同级，归当前题或小题所有。填空、简答至少有一处行内或独立作答区。 |
| `@material #id` | 阅读题包含一份或多份材料，每份正文写一次，多道小题可以共用。正文中的 `[[#id\|<text>]]` 为这一处原文命名，供设问引用或局部排版。 |
| `@subquestion <kind> #id refs=#target` | 写在阅读题内，至少一道。小题类型取选择、填空或简答，沿用该类型的题干、选项组、作答区写法。多个引用用英文逗号分隔，可指向本阅读题的材料或材料中的具名字词。 |

`@stem` 和 `@material` 接受多段正文，`@options` 只接受选项行。选择、填空、简答均可留独立作答区。各题型的普通正文都可包含列表。阅读题的题干、材料和小题依次书写。渲染器按小题的书写顺序编为（1）、（2）……，引用依标识查找。例如把阅读题的两个小题调换位置，只需移动各自的小题块。

## 渲染层怎样描述正文与版式

**正文采用轻量标记。** 在题干、材料中，空行分段，同段源文的普通换行视作一个空格。选项正文使用同一套行内写法。以下是本草案约定的子集。

| 题面内容 | 源文写法与含义 |
| --- | --- |
| 行内格式 | `**粗体**`、`*斜体*`、`~~删除线~~`。需要单独引用、加点或画线的文字用 `[[#id\|<text>]]` 定位，之后在排版块里指定效果。具名片段限同段纯文字，同一片段可叠加多项效果。 |
| 公式 | `$\frac{1}{2}$` 是行内公式，`$$...$$` 独占一行时是陈列公式。定界符内保留 LaTeX 数学源文，由数学排版器解释。 |
| 图片 | `![数轴示意](images/axis.png)` 代表带文字说明的图片，路径相对于源文。图跟随所属的题干、选项或材料。 |
| 列表与简单表格 | 连续的 `- 文字` 行构成普通列表。连续的、首尾有竖线的正文行组成表格，竖线分格，每行格数一致。行首格和首行均按普通数据格处理。例如两行分别写 `\| x \| 4 \| 10 \|` 和 `\| y \| 90 \| 51 \|`，保留两组配对数值。表头角色、合并格与跨页表留待后续版本。 |

正文保留符号可用反斜杠转义，例如 `\$` 表示金额符号，`\*` 表示字面星号，`\|` 表示格内竖线，`\\` 表示反斜杠。解析表格行时，转义字符、数学片段和具名片段内部的竖线都按片段内容处理，只有片段外未转义的竖线分格。所以 `$|x|$` 可以完整放入一个单元格。具名片段内的第一个未转义竖线隔开标识与原文。具名片段和数学片段各有明确的结束符，缺失时在源文位置报错。

**版式按标识指定。** 题目结束后，顶格写 `@layout`。块内每行先写 `#target`，再写一项或多项 `key=value`，用空格分隔。可再写 `@layout screen` 或 `@layout print`，沿用同一份题面。每种排版块最多一个。先应用默认值，再应用通用排版，最后以当前载体的同名属性覆盖。同一块对同一目标的同一属性只写一次。下表用斜杠分隔可选值，源文中每次选一个，例如 `underline=wavy`。

| 目标 | 可用属性 | 默认与效果 |
| --- | --- | --- |
| 选项组 | `columns=auto/1/2/4` | 默认自动。从 4、2、1 中取不超过选项数、等宽列内各项可单行容纳的最大列数，放不下就用单列。显式列数按给定列宽在格内折行。两种方式都按从左到右、从上到下排列并标 A、B、C……。 |
| 行内作答区 | `shape=line/parentheses/box`、`width=<number>em` | 默认横线、宽 4em。宽度取正数。宽度按所在文字的字号换算。只对显式声明的空位画线或框。 |
| 独立作答区 | `shape=line/box/space`、`lines=<integer>` | 默认留白一行，占所在正文栏宽。行数取正整数。两行横线画两条书写线，两行方框画一个两行高的外框。 |
| 具名字词 | `weight=bold/normal`、`font-style=italic/normal`、`emphasis-mark=dot-below/none`、`underline=solid/double/wavy/none`、`strike=true/false` | 默认沿用正文字体且无装饰。字下加点逐字对齐，下划线和删除线跟随同一段原文折行。 |

文档应能在排版前查出重复标识、未定义引用、小题引用的目标不属于同一阅读题的材料、属性用于错误的目标等问题。例如，`#units columns=2` 的目标必须是选项组。普通正文中的一串横线始终是文字，只有 `{{blank #id}}` 或 `@answer-area` 会建立作答区对象。

## 三道完整题面

下面三段都是可单独阅读的一份源文，题目为本稿自拟。每段后的说明给出核对排版所需的预期结果。

### 选择题 · 同一组选项分列显示

```text
@question choice #fractions
  @stem
    下列分数中，**大于** $\frac{1}{2}$ 的是{{blank #pick}}。
  @options #numbers
    - #quarter $\frac{1}{4}$
    - #three-quarters $\frac{3}{4}$
    - #half $\frac{1}{2}$
    - #two-fifths $\frac{2}{5}$

@layout
  #pick shape=parentheses width=3em
  #numbers columns=auto

@layout print
  #numbers columns=2
```

纸面上“**大于**”加粗，题干末尾在句号前留一对作答括号。四个分式排成两行，第一行 A、B，第二行 C、D。屏幕可以随宽度改排一列或四列，每个标号仍跟随原来的分式。

### 填空题 · 两个空位都留在句中

```text
@question fill-in #rectangle
  @stem
    一个长方形长 8 厘米，宽 3 厘米。

    它的周长是{{blank #perimeter}}厘米，面积是{{blank #area}}平方厘米。

@layout
  #perimeter shape=line width=4em
  #area shape=box width=5em
```

第一段给条件，第二段有两个作答区。周长的横线在“厘米”前，面积的方框在“平方厘米”前。调换两个分句时，移动各自的空位标识，指定的外形和宽度就会随原处内容一同移动。

### 阅读题 · 共享材料并引用具体字词

```text
@question reading #after-rain
  @stem
    阅读短文，完成下面两道小题。
  @material #passage
    雨停了，操场边的水洼[[#reflect|映]]着一小片蓝天。

    小禾绕开水洼，把石阶上的一只蜗牛轻轻移到草叶上。
  @subquestion choice #where refs=#passage
    @stem
      小禾把蜗牛移到了哪里？
    @options #places
      - #step 石阶上
      - #leaf 草叶上
      - #puddle 水洼里
  @subquestion short-answer #meaning refs=#passage,#reflect
    @stem
      加点的“映”字写出了怎样的景象？
    @answer-area #explanation

@layout
  #reflect emphasis-mark=dot-below
  #places columns=1
  #explanation shape=line lines=2
```

先排一次材料，再排两道小题。只有材料中的“映”字下有点，小题题干里再次出现的“映”保持普通字形。第一小题下列出三个选项，第二小题下画两行书写线。交换两道小题的源文位置后，显示序号随之变化，`#reflect` 仍指向材料里的那一个字，两行书写线仍归 `#meaning` 所有。

## 草案的验证边界

v0.1 选择了“题目块＋轻量正文＋具名排版规则”的写法。以上三例可作为后续实现与其他候选写法共用的对照题面。首轮验收可对照三个结果。窄屏重排后选项内容及顺序正确，两个空仍分别对应原单位，阅读小题换序后仍能找到原材料、加点字和所属作答区。真实题库的完整导入、跨页排版和教师试写还需另行验证。[研究范围与原题](README.md) · [更多题面样式](question-forms.md)
